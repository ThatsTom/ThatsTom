## Automação como arquitetura

Meu maior foco é construir processos digitais que conectem áreas, ferramentas e decisões em um único fluxo.

```text
WhatsApp → IA → CRM → Banco → Designer → Vendedor
```

```text
ERP → API → Validação → Automação → Banco → Dashboard
```

```text
Documentos → Embeddings → Busca Semântica → RAG → LLM → Resposta / Ação
```

```text
Dados externos → ETL → Machine Learning → Score → Alerta → Interface
```

```text
Aplicação → API → AWS EC2 → RDS / Aurora → Serviços
```

A ideia é sempre reduzir tarefas repetitivas, eliminar retrabalho, centralizar contexto e transformar processos fragmentados em pipelines intuitivos.

## Projetos em destaque

### Samira V2 — Agente inteligente de atendimento via WhatsApp

Projeto de automação comercial que combina LLM, WhatsApp Cloud API, Node.js, Supabase, webhooks e regras determinísticas.

O agente interpreta mensagens, executa ferramentas e movimenta diferentes etapas do processo comercial.

Principais recursos:

- interpretação semântica com LLM;
- execução de ferramentas;
- memória e estado persistente;
- coleta estruturada de dados em linguagem natural;
- transcrição e interpretação de áudio;
- criação e atualização de pedidos;
- envio de catálogo, preços e materiais;
- envio automático de solicitações para designer;
- recebimento e entrega de amostras digitais;
- fluxo de revisão de arte;
- handoff inteligente para atendimento humano;
- registro em CRM;
- idempotência e validações determinísticas.

**Objetivo:** transformar uma conversa em um pipeline operacional completo, e não apenas em um chatbot.

## Formação aplicada — Challenge SOMPO Seguros

Durante a graduação, várias disciplinas trabalham sobre um mesmo contexto de negócio: **análise e prevenção de riscos em operações agrícolas para a SOMPO Seguros**.

Isso permite evoluir a solução em camadas, em vez de estudar cada tecnologia de forma isolada.

```text
Problema de negócio & Sprint Planning
              ↓
Sensores e telemetria com ESP32
              ↓
Modelagem e estruturação dos dados
              ↓
Análise de risco com Python
              ↓
Cibersegurança e análise de anomalias
              ↓
Machine Learning
              ↓
Cloud Computing com AWS
              ↓
Redes Neurais / Deep Learning
              ↓
Estatística aplicada com R & Python
              ↓
Protótipo integrado e orientado a decisão
```

### Engenharia de produto e evolução incremental

Os desafios incluem organização de backlog, revisão de User Stories, definição de critérios de aceitação, priorização, Sprint Planning, wireframes, prototipação e demonstração de funcionalidades funcionando de forma incremental.

Isso conecta a parte técnica à visão de **produto, usuário e valor de negócio**.

### IoT, sensores e telemetria

Construção de protótipos com **ESP32** e sensores para representar condições ambientais e operacionais, evoluindo de leituras básicas para telemetria estruturada, classificação local de risco e acionamento de alertas.

Entre os elementos trabalhados estão:

- DHT22;
- HC-SR04 e outras entradas de contexto;
- modos de operação;
- regras locais com `if/else` e funções;
- classificação normal / atenção / crítico;
- LED e buzzer como atuadores;
- saída estruturada para integração com outras camadas da solução.

### Data Science e engenharia de dados

Estruturação do problema de negócio em dados utilizáveis para análise e IA, incluindo:

- definição de entidades e atributos;
- dicionário de dados;
- limpeza e padronização;
- tratamento de valores ausentes e inconsistências;
- análise exploratória;
- correlação e análise temporal;
- criação de features;
- score de risco ambiental e operacional;
- segmentação e simulação de cenários;
- geração de recomendações;
- preparação do dataset para Machine Learning.

### Python aplicado à tomada de decisão

Desenvolvimento de soluções em Python capazes de ingerir dados, aplicar regras de negócio, calcular scores, gerar alertas, rankings e relatórios.

Os exercícios evoluem conceitos fundamentais de programação para aplicações orientadas a dados utilizando listas, dicionários, funções, condicionais, `pandas`, `lambda`, `apply` e modularização.

### Cibersegurança Cognitiva

Construção de um fluxo IoT completo para entender como os dados trafegam e onde surgem riscos:

```text
Dispositivo IoT → HTTP/TCP → Servidor → Armazenamento → Análise → Alerta
```

A evolução envolve identificação de exposição de IP, ausência de autenticação, tráfego sem criptografia, possíveis interceptações e análise de dados suspeitos, repetidos, incompletos ou fora do padrão.

### Machine Learning & Modelling

Os desafios percorrem o ciclo de modelagem desde a definição do problema até a avaliação de modelos:

```text
Problema de negócio
      ↓
Definição do alvo
      ↓
Features
      ↓
EDA e preparação
      ↓
Treinamento
      ↓
Validação
      ↓
Tuning
      ↓
Interpretação
      ↓
Score / API / Dashboard
```

O contexto envolve previsão e classificação de risco de sinistro, identificação dos principais fatores associados ao risco e transformação do resultado em uma solução utilizável pelo negócio.

### Cloud Computing com AWS

Experiência prática colocando aplicações Python na nuvem:

```text
Python / Flask
      ↓
AWS EC2
      ↓
Security Groups
      ↓
SSH
      ↓
API pública
      ↓
Amazon RDS / PostgreSQL
```

Os desafios incluem provisionamento de instâncias EC2, acesso via SSH, configuração de portas, publicação de API Flask, testes HTTP e conexão da aplicação com banco de dados gerenciado no RDS.

### Redes Neurais e Deep Learning

Estudo aplicado da escolha de arquiteturas de acordo com o tipo de problema:

- MLP para dados tabulares;
- LSTM / GRU para séries temporais;
- CNN para análise de imagens.

A evolução inclui preparação de datasets, pré-processamento, divisão treino/teste, treinamento, hiperparâmetros, avaliação inicial, análise de overfitting e construção de protótipos para disponibilização do modelo.

### Statistical Computing with R & Python

Aplicação de estatística computacional para transformar dados em evidência quantitativa:

- distribuição de frequências;
- gráficos de setores, barras, histogramas e boxplots;
- análises univariadas;
- medidas de tendência central;
- medidas de dispersão;
- medidas separatrizes;
- geração de insights e relatórios técnicos orientados à tomada de decisão.
