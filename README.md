## Projetos selecionados

### Samira V2 — Agente de atendimento e automação comercial

Agente inteligente integrado ao **WhatsApp Cloud API, OpenAI, Node.js e Supabase**, desenvolvido para automatizar etapas reais do processo comercial.

**Principais responsabilidades:** interpretação de mensagens, execução de ferramentas, memória de contexto, transcrição de áudio, coleta de dados, geração de pedidos, integração com fluxo de designers, revisão de artes, CRM, handoff humano e validações determinísticas.

> O objetivo do projeto é transformar uma conversa em um **pipeline operacional completo**, e não apenas em um chatbot.

### [AgriShield](https://github.com/ThatsTom/agrieshield-sompo)

Aplicação Full Stack para **análise de risco em operações agrícolas**, combinando Python, FastAPI, React, ETL, engenharia de variáveis e integração com fontes climáticas e geoespaciais.

`Python` `FastAPI` `React` `Pandas` `NumPy` `ETL` `APIs externas`

### [Machine Learning — Classificação de Risco IoT](https://github.com/ThatsTom/sprint3-mlm)

Pipeline de Machine Learning para classificação de risco com preparação de dados, Regressão Logística, Random Forest, validação holdout, métricas, tuning com GridSearchCV e interpretação de variáveis.

`Python` `Scikit-learn` `Pandas` `NumPy` `Jupyter`

### [Cognitive Cybersecurity — IoT Risk Pipeline](https://github.com/ThatsTom/sprint3-cyber)

Sistema em Python para simulação IoT, comunicação HTTP, validação, armazenamento, análise de anomalias e geração de score e alertas de risco.

`Python` `IoT` `HTTP` `JSON` `Cybersecurity`
