## Automação como arquitetura

Meu maior foco é construir processos digitais que conectem áreas, ferramentas e decisões em um único fluxo.

```text
WhatsApp → IA → CRM → Banco → Designer → Vendedor
```

```text
ERP → API → Validação → Automação → Banco → Dashboard
```

```text
Documentos → Embeddings → Busca Semântica → RAG → LLM → Resposta / Ação
```

```text
Dados externos → ETL → Machine Learning → Score → Alerta → Interface
```

```text
Aplicação → API → AWS EC2 → RDS / Aurora → Serviços
```

A ideia é sempre reduzir tarefas repetitivas, eliminar retrabalho, centralizar contexto e transformar processos fragmentados em pipelines intuitivos.

## Projetos em destaque

### Samira V2 — Agente inteligente de atendimento via WhatsApp

Projeto de automação comercial que combina LLM, WhatsApp Cloud API, Node.js, Supabase, webhooks e regras determinísticas.

O agente interpreta mensagens, executa ferramentas e movimenta diferentes etapas do processo comercial.

Principais recursos:

- interpretação semântica com LLM;
- execução de ferramentas;
- memória e estado persistente;
- coleta estruturada de dados em linguagem natural;
- transcrição e interpretação de áudio;
- criação e atualização de pedidos;
- envio de catálogo, preços e materiais;
- envio automático de solicitações para designer;
- recebimento e entrega de amostras digitais;
- fluxo de revisão de arte;
- handoff inteligente para atendimento humano;
- registro em CRM;
- idempotência e validações determinísticas.

**Objetivo:** transformar uma conversa em um pipeline operacional completo, e não apenas em um chatbot.

### [AgriShield](https://github.com/ThatsTom/agrieshield-sompo)

Plataforma para análise de risco em operações agrícolas utilizando Python, FastAPI, React, Pandas e NumPy.

```text
Cadastro
   ↓
Coleta de dados externos
   ↓
ETL
   ↓
Engenharia de variáveis
   ↓
Indicadores de risco
   ↓
FastAPI
   ↓
Dashboard React
```

O projeto integra fontes climáticas e geoespaciais como NASA POWER, Open-Meteo, INMET e MapBiomas.

---

### [Machine Learning — Classificação de Risco IoT](https://github.com/ThatsTom/sprint3-mlm)

Projeto acadêmico em Python para classificação de risco em dispositivos IoT.

Inclui:

- preparação e transformação de dados;
- StandardScaler e OneHotEncoder;
- Regressão Logística;
- Random Forest;
- holdout;
- Accuracy, Precision, Recall, F1 e AUC ROC;
- tuning com GridSearchCV;
- Permutation Importance.

---

### [Cognitive Cybersecurity — IoT Risk Pipeline](https://github.com/ThatsTom/sprint3-cyber)

Pipeline em Python para simulação, coleta, validação, armazenamento e classificação de risco de dispositivos IoT.

```text
IoT → HTTP → Validação → Storage → Risk Engine → Score → Relatórios
```
